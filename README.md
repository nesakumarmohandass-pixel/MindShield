# MindShield

AI-powered digital wellness coach with a unique "Digital Twin" that evolves based on your phone habits.

## Setup

1. Open this project in Android Studio
2. Add your API keys to `local.properties`:
   ```
   GEMINI_API_KEY=your_gemini_api_key
   REVENUECAT_API_KEY=your_revenuecat_api_key
   ```
3. Sync Gradle and run on emulator or device

## Features

- 🧠 AI Coach powered by Google Gemini
- 🪞 Digital Twin that reflects your habits
- 📊 Screen time tracking & insights
- 🎯 Focus mode with breathing exercises
- 💎 Premium subscriptions via RevenueCat
- 📱 Samsung Galaxy foldable support

## Tech Stack

- Kotlin + Jetpack Compose + Material 3
- Google Gemini AI (Flash)
- RevenueCat SDK
- Room Database + DataStore
- Hilt DI
- WorkManager
- Lottie Animations
